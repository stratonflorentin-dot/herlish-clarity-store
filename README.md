# Herlish Clarity Store

Futuristic one-page website for **Herlish Clarity Store** — 100% pure & natural castor oil for longer, stronger, healthier hair. Made in Tanzania. Order via WhatsApp.

## Stack

- React 19 + TypeScript + Vite
- Tailwind CSS v3 + shadcn/ui (theme system & component library)
- Lucide icons, canvas particle effects, glassmorphism, scroll reveals

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build   # outputs to dist/
```

Deployed on Vercel.
